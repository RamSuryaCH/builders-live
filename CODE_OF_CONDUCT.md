# Code of Conduct

Builders Live is a source-available project for non-commercial community meetups.
People running a room, and people contributing, should be able to take part without harassment.

## Our standard

- Be respectful to attendees, organizers, and contributors.
- Assume good intent, and be direct about problems.
- Do not insult, harass, or publish other people's private information.
- Do not use this project for commercial services. See the license.

## Where it applies

This applies in issues, pull requests, and in rooms that run this software when the organizer has adopted this conduct.

## Enforcement

Report a problem through GitHub: https://github.com/RamSuryaCH

Do not include host PINs, session tokens, or cloud account details in a report.

The maintainer may remove comments, reject contributions, or block further interaction when this standard is broken.
